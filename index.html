What this prototype checks

Aseprite JSON-array / JSON-hash exports with unrotated PNG frames. It checks declared dimensions, frame rectangles, filename collisions, positive durations, trim geometry and tag index ranges.

Rotated frames and slice metadata are marked as unchecked. Duplicate keys inside JSON objects, missing external files beyond the selected PNG, animation direction semantics and in-engine rendering are not validated. A clean result is not an engine compatibility certificate.
